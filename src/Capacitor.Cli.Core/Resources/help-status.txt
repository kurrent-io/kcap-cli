kcap status — Show server, auth, hook, and daemon status

Usage: kcap status [--json]

Options:
  --json     Report the same facts as one JSON document on stdout and nothing
             else, for a tool driving setup rather than a person reading it.
             Carries a top-level `configured` flag: a server is set and this
             CLI holds credentials for it. An unreachable server is still
             configured -- that is a network fact, not a setup one.

Reports:
  Server     Configured base URL and reachability check
  Auth       Stored credentials and token expiry
  Hooks      Per-agent integration state: Claude plugin, Codex / Cursor /
             Copilot / Gemini / Kiro hooks, the Pi / OpenCode live-ingest
             extensions, and the Antigravity hooks block (✓ installed,
             ✗ not installed)
  Daemon     Whether the daemon is running (PID file check)
