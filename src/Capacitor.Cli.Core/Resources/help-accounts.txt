Usage: kcap accounts [list|add|remove|rename|rewire|refresh]

Records every Claude Code config directory (CLAUDE_CONFIG_DIR) and Codex home (CODEX_HOME)
you use, not only the default one.

  kcap accounts                         List accounts, their recording state, and directories
                                        found on this machine that are not added yet
  kcap accounts add <claude|codex> <dir> [--skip-codex-network-access] [--json]
                                        Add a directory, install kcap's recording into it, and
                                        refresh it
  kcap accounts remove <id|dir> [--json]
                                        Remove kcap's recording from an account and forget it
                                        (the directory and its login are left alone)
  kcap accounts rename <id|dir> <label> [--json]
                                        Change the label shown for an account
  kcap accounts rewire [<id|dir>] [--skip-codex-network-access] [--json]
                                        Reinstall recording into one or every account
  kcap accounts refresh [<id|dir>] [--json]
                                        Ask the vendor CLI who is signed in to one or every
                                        account (and, for Codex, its usage limits); prints a
                                        line per account and exits 1 when a step failed

Options:
  --skip-codex-network-access           Don't enable Codex sandbox network access for your
                                        server(s) in a Codex account's config.toml
  --json                                add, remove, rename, rewire and refresh print one JSON
                                        line on stdout: action, account_id, succeeded, steps
                                        (name, succeeded, detail), revision (the account
                                        registry revision the command committed, null if none)
                                        and error. Errors still go to stderr; exit code 0 only
                                        on success.
